Wie ben ik?

Hallo! Mijn naam is Nathaniel Rasmijn. Ik ben 24 jaar oud, geboren en getogen op Aruba, en op dit moment woonachtig in Nederland voor mijn studie. Ik zit in het tweede jaar van de opleiding Software Engineering aan De Haagse Hogeschool.

Mijn passie voor software ontwikkeling begon tijdens ik 12 jaar oud was. Ik begon met tutorials in youtube te kijken hoe een game kan maken. Daarna heb ik mijn eerste snake game gebouwd in java met Eclipse. Daarna begon ik met Unity en C#. Ik kan C# basics coderen, maar ben ik benieuwd om meer te leren. Nu ben ik bezig met plugins voor games zoals minecraft te bouwen en ook websites voor kleine bedrijven in Aruba te bouwen.

Ervaringen

Game & Plugin Development

Ik heb ruime praktijkervaring opgedaan met server-side plugin development voor games zoals Minecraft met behulp van Java en de Paper/Spigot API's. Hierbij heb ik gewerkt met event-driven architecturen, databasekoppelingen en prestatiemonitoring voor actieve spelersservers.
