Mijn Eerste Blog Post

Software development is een interessante vak waar ik erg van hou. Toen ik voor het eerst een game maakte, dacht ik niet dat er zoveel werk en gedachten nodig waren. Ik dacht dat ik gewoon code gaan schrijven en de ideeën zou uitwerken. Maar dan kwam ik op HBO en ontdekte dat het veel meer was dan ik had gedacht. Er is niet alleen game development, maar ook web, app en andere types van development. Ook ontdekte ik dat eerst moeten we scrum implementeren. Dan het database maken op verschillende manieren zoals het UML,RRM enz. Daarna alles op SQL zetten en de backend bouwen. Dan pas de designs en ook het frontend bouwen. Een van mijn favorite dingen is het oplossen van problemen en het bouwen van nieuwe functies. Ook heb ik ontdekt dat ik van website ontwerpen hou. Je ziet wat je code op een live site en dat is echt cool!
